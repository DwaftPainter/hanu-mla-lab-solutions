# Week 1 Lab: K-Nearest Neighbours

This directory contains the Week 1 KNN tutorial source and the Eedi response
data used by the lab.

## Source files

- `knn.py`: user- and item-based KNN experiments
- `majority_vote.py`: majority-vote baseline
- `utils.py`: data loading and evaluation helpers
- `generate_report.py`: report generation helper
- `fill_handout.py`: tutorial handout helper

Run the main experiment from this directory:

```bash
python knn.py
```

The script writes plots and prediction arrays locally; those generated files
are ignored by the repository.
