# Week 2 Lab: Decision Trees

This directory contains the Week 2 decision-tree tutorial source and the Eedi
response data used by the lab.

## Source files

- `decision_tree.py`: depth sweep, validation curve, and test evaluation
- `utils.py`: data loading and evaluation helpers
- `generate_report.py`: report generation helper

Run the main experiment from this directory:

```bash
python decision_tree.py
```

The script writes plots locally; those generated files are ignored by the
repository.
